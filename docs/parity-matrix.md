# مصفوفة توافق الميزات

> الغرض: تحويل عبارة «مثل المنافس» إلى قائمة قابلة للقياس. كل صف إما مُنجز ومُختبر، أو مجدول، أو خارج النطاق.
> الحالات: `done` منجز ومختبر — `wip` قيد العمل — `todo` مجدول — `later` مرحلة لاحقة — `out` خارج النطاق.

> **حالة التحقق الآن:** سلسلة أدوات Rust تعمل (`vcvars64.bat` من
> `G:\Program\VC`)، و`cargo test --workspace` **87 اختباراً ناجحاً**
> (core 50، server 27، store 10)، و`npm.cmd run build` يمرّ: فحص
> العقد 111 + فحص Rust البنيوي 7 ملفات + `tsc` نظيف + حزمة vite.
> صف `done` هنا يعني: اختبار ناجح يقابل الميزة. `wip` تعني: كود
> مكتوب وموثّق وتحت التنفيذ/الربط، أو أن شيئاً من سلوكها غير مُختبر.
