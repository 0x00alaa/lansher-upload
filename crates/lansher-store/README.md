# وحدة التخزين — `lansher-store`

**ما هي:** SQLite. المخطط، الترحيلات، كشف التعارض، الإحصائيات.

**ما لا يدخلها:** لا تكتب داخل `event.rs` ولا `rule.rs` ولا `types.ts`
ولا `schemas/*.json`. العقد يُقرأ ولا يُكتب. ولا محرّك قواعد هنا.

**كيف تُبنى:** عضو في مساحة عمل Rust في الجذر، ويعتمد على
`lansher-core` بالأنواع فقط. `cargo build -p lansher-store`.
الاعتماد `rusqlite` مدمج فلا يحتاج SQLite مثبَّتة.

**كيف تُختبر:** `cargo test -p lansher-store` (١٠ اختبارات) على قاعدة
في الذاكرة، بلا ملف على القرص.

**من يملكها:** وحدة التخزين. **تُسلَّم لـ:** مسؤول بيانات. **لا تلمس:**
العقد الرباعي، المحرك.

ملاحظة اليوم: الوحدة مكتوبة ومختبَرة لكنها **غير موصولة** بالواجهة ولا
بالجسر بعد. «كل SQL داخل هذا المجلد فقط، لا استعلام في غيره» قاعدة
مطلوبة عند التوصيل.

التفاصيل الكاملة: `OWNERS.md` و`tasks/` و`AGENTS.md`.
