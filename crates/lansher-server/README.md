# وحدة الجسر — `lansher-server` (Rust)

> **ليش سُمّيت هكذا:** الاسم يوهم خادماً سحابياً. هي **جسر محلي داخل
> التطبيق**: يربط واجهة Tauri بمحرك `lansher-core`. الخادم السحابي هو
> `server/` بلغة Node، وهو مسار منفصل تماماً. انظر `server/README.md`.

**ما هي:** طلب ورد واحد، مصادقة محلية، تنفيذ إجراءات، تشخيص. تستقبل
`bridge_request` من الواجهة وتعيد تقرير المحرك.

**ما لا يدخلها:** لا تكتب العقد الرباعي. تقرأه فقط. لا I/O: لا شبكة ولا
قرص، فالمحرك خلفها خالص. لا تحقّق قواعد.

**كيف تُبنى:** عضو في مساحة عمل Rust في الجذر، ويعتمد على
`lansher-core` بالأنواع. `cargo build -p lansher-server`.

**كيف تُختبر:** `cargo test -p lansher-server` (٢٧ اختباراً) على أنواع
وهمية، بلا شبكة.

**من يملكها:** وحدة الجسر. **تُسلَّم لـ:** مدرّس Rust، نفسه القادر على
وحدة المنطق. **لا تلمس:** العقد، `UI/`.

ملاحظة اليوم: **غير موصولة** بـ`lansher-store` بعد. واسمها محل مراجعة
في `tasks/W0.md` (W0.7) ولا يُغيَّر بلا موافقة.

التفاصيل الكاملة: `OWNERS.md` و`tasks/` و`AGENTS.md`.
