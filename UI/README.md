# وحدة الواجهة — `UI/`

**ما هي:** الواجهة الحقيقية للتطبيق: React + TypeScript. أربعة أجزاء:
الشكل (`src/styles/`)، مكتبة المكوّنات (`src/ui/`)، الصدفة
(`src/shell/`)، الشاشات (`src/views/`). ومصدر العقد: `src/types.ts`،
وحبل الوصل مع المحرك: `src/bridge.ts`.

**ما لا يدخلها:** لا منطق أعمال. لا محرّك قواعد ولا مطابقة أحداث ولا
حساب قيمة هدية. لا I/O مباشر: كل شيء يمرّ بأمر `bridge_request` واحد،
والمحاكي يرسل `push_event` ويستقبل تقرير المحرك. لا استيراد من Node أو
Python.

**كيف تُبنى:** لا تُبنى من داخل `UI/`. البناء من `apps/desktop`،
لأن `node_modules` هناك: `npm.cmd run build` يوجّه `vite.config.ts`
جذره إلى `UI/` ويخرج إلى `apps/desktop/dist`. للتطوير: `npm.cmd run dev`.

**كيف تُختبر:** فحص الأنواع `tsc --noEmit` ضمن البناء، وفحص العقد
`tools/check-contract.mjs` يقرأ `types.ts` ويقارنه بـRust و`schemas/`.
لا اختبارات وحدة في الواجهة اليوم.

**من يملكها:** وحدة الواجهة. **`types.ts` مملوك لوحدة المنطق** لا لها،
فلا تعدّله إلا باتفاق. **لا تكتب العقد الرباعي.** **لا تلمس:**
`crates/`، `server/`.

التفاصيل الكاملة: `OWNERS.md` و`tasks/` و`AGENTS.md`.
