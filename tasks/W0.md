# W0 — ترتيب البيت قبل ما يدخل الرسّامون

> **شو هي:** خطوة واحدة أنظف فيها أربعة أشياء، بدون أي ميزة جديدة.
> **ليش لازم:** بعد W0 يبدأ ثلاثة وكلاء مع بعض. لو البنية مشوّهة
> الآن، كل واحد راح يفتح الملف الغلط.

## أول شي: المصطلحات

| المصطلح | شو يعني بلغة بسيطة |
|---------|--------------------|
| **العقد الرباعي** | أربع أماكن لازم تنكتب فيها الحقول نفسها مع بعض: ملف Rust، و`types.ts`، و`schemas/*.json`، والوثيقة. تكتب في وحدة بس؟ البناء يفشل ويخبرك |
| **نقطة التصادم** | المكان الوحيد الذي ممكن اثنين يشتغلوا عليه مع بعض. هو نفسه العقد الرباعي. لذلك وكيل واحد بس يملكه في كل موجة |
| **البوابة** | الفحصان اللذين ما ينكتب الشغل إلا إذا نجحا. هم `cargo test` و`npm.cmd run build` |
| **ملف ميت** | كود موجود بالمجلد بس ما يقراه أي بناء. عديم الفائدة، وأسوأ من الفقد: يفتح باب التعديل بالغلط |
| **`node_modules`** | المكتبات المنزّلة. ما نكتب داخلها أبداً |
| **`Cargo.toml`** | بطاقة هوية حزمة Rust. إذا غيّرنا اسم مجلد لازم يتغير هذا معه |
| **`tsconfig.json`** | ملف يقول للمدقّق: افحص هذه الملفات |
| **`vite.config.ts`** | ملف يقول للبناء: الواجهة من `UI`، لا من `apps` |
